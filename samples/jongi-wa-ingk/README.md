# 계간 종이와 잉크 — 시험용 잡지 20쪽

PrintGuard가 잡아내는 오류를 일부러 심은 자료입니다. `samples/build_magazine.py`로 다시 만들 수 있습니다.

## 이 폴더를 통째로 올리세요

IDML은 사진을 **링크로만** 들고 있습니다. `jongi-wa-ingk.idml` 하나만 올리면 사진이 따라오지 않아
‘끊긴 이미지 링크’가 뜹니다. `Links/`가 같이 있어야 그대로 열립니다.

```
jongi-wa-ingk/
  jongi-wa-ingk.idml    편집 파일 — 원본 수정 화면에 올립니다
  jongi-wa-ingk.pdf     검수용 PDF — 인쇄 검수 화면에 올립니다
  Links/                사진 5장
```

## 돌려 보는 순서

1. **인쇄 검수**에 `jongi-wa-ingk.pdf`를 올립니다(완성 크기 A4, 도련 3mm, 후가공 중철·무선 제본).
2. 결과에서 **교정 목록 복사**를 누릅니다.
3. **원본 수정**에서 이 폴더를 통째로 올리고, 복사한 글을 붙여 넣고 반영합니다.
4. 고친 PDF를 다시 검수하면 맞춤법 지적이 사라집니다.

- 11쪽: 맞춤법: 금새
